
# HR Analytics Using Python

## Project Overview
This project focuses on analyzing Human Resources (HR) data using Python. The main purpose is to explore employee information and understand patterns in the dataset.

## Project Objectives
- Explore and understand HR data.
- Perform data cleaning and preprocessing.
- Analyze employee-related information.
- Identify patterns and insights using data analysis.
- Create visualizations to present the findings.

## Tools and Technologies
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Project Workflow
1. Import the required libraries.
2. Load the dataset.
3. Understand the dataset structure.
4. Perform data cleaning.
5. Conduct Exploratory Data Analysis (EDA).
6. Create data visualizations.
7. Analyze the results.

## Project File
- HR Analytics Python Project.ipynb – Contains Python code, analysis and visualizations.

## Learning Outcomes
Through this project, I gained practical experience in Python, data cleaning, exploratory data analysis and data visualization.
